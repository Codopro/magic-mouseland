# こどプロ れんしゅうひろば

小学校低学年むけの、**キーボードとマウスの操作をあそびながら練習できる**ブラウザゲーム集です。
インストール不要、ブラウザだけで動きます。

👉 **[あそぶ](https://codopro.github.io/magic-mouseland/)**

| ゲーム | ないよう |
|---|---|
| ⌨️ [キーボードクエスト](https://codopro.github.io/magic-mouseland/typing_practice.html) | ホームポジションからローマ字入力まで、ステージ形式でタイピングを練習します。マスコットの**キイちゃん**が打ち間違いに合わせてアドバイスをくれます。 |
| 🖱️ [まほうのマウスランド](https://codopro.github.io/magic-mouseland/mouse_practice.html) | クリック・ダブルクリック・ドラッグ＆ドロップの3つを、ミニゲームで練習します。マスコットの**マウくん**がナビゲートします。 |

---

## 特徴

- **インストール不要** — HTML を開くだけ。ビルド工程もサーバーサイドもありません
- **依存パッケージゼロ** — 各ゲームは HTML / CSS / バニラ JavaScript の 1ファイル構成
- **セーブはブラウザ内** — `localStorage` に自動保存されます（サーバーに何も送信しません）
- **こどもに読みやすい表記** — ひらがな中心の UI と丸ゴシックフォント

## あそびかた

[GitHub Pages](https://codopro.github.io/magic-mouseland/) を開くだけです。

ローカルで動かす場合は、`file://` だと一部ブラウザで音や画像が読めないことがあるため、簡易サーバー経由を推奨します。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。

> **メモ**: ブラウザの自動再生ブロックのため、キーボードクエストの BGM は画面を最初にクリックした時点で鳴り始めます。

## 動作環境

Chrome / Edge / Firefox / Safari の最新版。画像に WebP、BGM に MP3 を使っています（いずれも 2020 年以降の主要ブラウザで対応）。

## リポジトリ構成

```
.
├── index.html              ランディングページ（2ゲームへのリンク）
├── typing_practice.html    キーボードクエスト本体（HTML/CSS/JS 一体型）
├── mouse_practice.html     まほうのマウスランド本体（HTML/CSS/JS 一体型）
├── image/                  2ゲーム共通の画像フォルダ
│   ├── bg_common.jpg           背景（タイピング）
│   ├── kii_chan_{normal,fail,clear}.webp    キイちゃんの表情差分
│   ├── title_logo.webp         ロゴ（マウスランド）
│   ├── mau_kun_{normal,fail,clear}.webp     マウくんの表情差分
│   └── creature_0〜5.webp      ダブルクリックで孵化する生き物
└── audio/                  キーボードクエスト用
    ├── bgm_*.mp3               タイトル・ゲーム・リザルトの BGM（ループ）
    └── se_*.wav, key_click_soft.wav   打鍵音・ミス音・決定音など
```

まほうのマウスランドは BGM・効果音を Web Audio API で合成しているため、音声ファイルを持ちません。

キイちゃん／マウくんの表情差分は、身体の縮尺・接地位置・色のトーンを3種そろえてあるため、
表情を切り替えても横ズレや大きさの変化が起きません。

## アセットの最適化について

公開用に、アセットを次のとおり最適化しています（**合計 32.3MB → 3.7MB**）。

| 対象 | 処理 | 劣化 |
|---|---|---|
| マスコット・生き物・ロゴ | 実表示サイズに合わせて縮小し、**WebP 可逆圧縮**で保存 | 縮小後の画素と完全一致（可視画素の差分ゼロ） |
| キイちゃん3枚 | 上記に加え、マウくんとトーンを揃えるため CIELAB 上で彩度を 0.80 倍 | 明度・色相は保持（色相ずれ平均 0.72°） |
| 背景 (`bg_common.jpg`) | 原本をそのままコピー | なし（再エンコードは二重劣化かつ削減効果なしのため見送り） |
| BGM | WAV → MP3（VBR 約 100kbps） | 音質 SNR 約 32dB |
| 効果音 | WAV のまま据え置き | なし（短尺のため MP3 化による遅延を避ける） |
